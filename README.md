# TERA — Туристический сайт

Карточки путешествий, описание маршрутов и форма демонстрационной заявки.

**[Открыть демонстрацию](https://portfolio7.ru/portfolio-demos/altai/)** · [Все проекты](https://portfolio7.ru/portfolio-demos/)

## Возможности и технологии

HTML, CSS и JavaScript; сервер на стандартной библиотеке Python, SQLite для тестовых данных.

Проект создан для портфолио. Название и данные вымышлены; реальные платежи, доставка и бронирования не выполняются. Не вводите настоящие персональные или платёжные данные.

Иллюстрации в проекте сгенерированы для демонстрационного сайта.

## Локальный запуск

Нужен Python 3.10 или новее. Дополнительные Python-зависимости не требуются.

```bash
python server.py --port 8000
```

Откройте <http://127.0.0.1:8000/>.

Сервер слушает только `127.0.0.1`. Тестовые заявки хранятся в `data/demo.sqlite3`; каталог исключён из Git. Старые записи автоматически очищаются примерно через неделю. Для изменения расположения данных можно задать `PORTFOLIO_DATA_DIR`.

## Проверка

```bash
python tests/smoke.py
```

`public/` содержит интерфейс и ресурсы. Страница адаптирована для мобильных и больших экранов.
